# Visualisation Code

This repository contains the source code behind my visualisation blog posts.

- `bloom-filters/` - <https://samwho.dev/bloom-filters>
- `hashing/` - <https://samwho.dev/hashing>
- `memory-allocation/` - <https://samwho.dev/memory-allocation>
- `load-balancing/` - <https://samwho.dev/load-balancing>
- `turing-machines/` - <https://samwho.dev/turing-machines>
- `reservoir-sampling/` - <https://samwho.dev/reservoir-sampling>
- `big-o/` - <https://samwho.dev/big-o>

The code was largely rewritten in October 2026 to use Lit. You can go back
further in the history of this repo to see older code, and I maintain an old
version of the site at <https://old.samwho.dev>.

This code isn't intended to be tremendously usable out of the box. It builds
with `bun run build` but there's no example pages or post markdown on purpose.
It's MIT licensed and you are welcome to use it and learn from it. If you want
to point your agent at this repo and ask for something to be built "samwho
style" by all means go for it. Let me know how it turns out.

All I ask is that you please don't republish my posts verbatim without
permission. Thank you.
